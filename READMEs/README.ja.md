# OMIT
Oneul-ui Master's Impeccable Tailoring  
間接移動武器を活用したローグライクゲーム

## コアコンセプト
- 間接移動武器：武器はプレイヤーの前方へ自動的に移動します。
- 協力又は競争：マルチプレイで協力または競争が可能です。
