# OMIT
Oneul-ui Master's Impeccable Tailoring  
간접 이동 무기를 활용하는 로그라이크 게임

## 핵심 콘셉트
- 간접 이동 무기: 무기는 플레이어 앞으로 자동으로 이동합니다.
- 협동 또는 경쟁: 멀티 플레이를 통해 협동 또는 경쟁할 수 있습니다.

## 개발 상황

**열일 끝**
- [v] 플레이어 이동
- [v] 무기 시스템
- [v] 기본 적  

**열일 중**
- [ ] 적 소환
- [ ] 강화와 경험치
- [ ] 인벤토리
- [ ] 레벨 곡선
- [ ] 네트워크 통신

## 기술 스택
- 엔진: Unity 6000.3.9f1
- 언어: C#
- 사용 에셋: Odin Inspector, UniTask
